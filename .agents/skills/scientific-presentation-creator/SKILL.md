# Scientific Presentation Creator

Этот навык определяет стандарт разработки университетских академических и научно-технических презентаций (`.pptx`) для курса **«Физические основы нанотехнологий»** (ГУАП) и смежных дисциплин двумя взаимодополняющими способами:
1. **Интерактивное управление живым окном Microsoft PowerPoint через MCP-сервер `powerpoint`** (пошаговое создание/редактирование на экране пользователя, переключение слайдов, снимки `slide_snapshot`, шаблоны и заметки).
2. **Пакетная кодогенерация на Python (`python-pptx` + `matplotlib`/`numpy` + `pywin32`)** (быстрая сборка презентации целиком, высокоточные расчетные графики `300 DPI`, автоматическое оформление по дизайн-коду ГУАП и массовый рендер превью).

## 1. Архитектура инструментов и зависимости (Dependencies & Requirements)

Для полноценной работы навыка в проекте должны быть доступны следующие программы, MCP-серверы и Python-пакеты:

### 1.1. Внешние приложения (OS & Desktop Applications)
- **ОС:** Windows (требуется для COM-автоматизации `PowerPoint.Application` и MCP-сервера `powerpoint`).
- **Microsoft PowerPoint (Desktop / Office 365 / 2019+):** обязателен для живого управления через MCP-сервер `powerpoint` и точного экспорта PNG-превью слайдов через `pywin32` (`Slide.Export`).
- **Менеджер окружения `uv`:** для быстрого запуска генераторов (`uv run python ...`).

### 1.2. Подключенные MCP-серверы (MCP Servers)
- **MCP-сервер `powerpoint`** (схемы инструментов: `<appDataDir>/mcp/powerpoint/*.json`, вызов через `call_mcp_tool(ServerName="powerpoint", ToolName=..., Arguments=...)`):
  - `manage_presentation` — открытие (`open`), создание (`create`), сохранение (`save`, `save_as`) и закрытие (`close`) презентации в живом окне PowerPoint.
  - `list_templates` / `analyze_template` — просмотр доступных шаблонов `.potx`/`.pptx` и анализ макетов/плейсхолдеров.
  - `add_slide_with_layout` / `populate_placeholder` — добавление слайда с выбранным макетом и заполнение его плейсхолдеров.
  - `manage_slide` — дублирование (`duplicate`), перемещение (`move`) и удаление (`delete`) слайдов.
  - `switch_slide` — переключение активного слайда на экране пользователя (1-based индекс).
  - `slide_snapshot` — мгновенный снимок текущего слайда из открытого окна PowerPoint для визуальной проверки.
  - `add_speaker_notes` — запись методической речи лектора в заметки докладчика.
  - `add_animation` — добавление точечной анимации в открытой презентации.
  - `evaluate` — прямое выполнение COM/VBA-выражения над объектной моделью презентации PowerPoint.
- *(Опционально для 3D-структур)* **MCP-сервер `science_biomolecular_structure_viewer_mcp`** — интерактивная 3D-визуализация молекулярных и кристаллических структур в боковой панели.

### 1.3. Python-библиотеки (прописаны в `pyproject.toml` и `requirements.txt`)
- `python-pptx>=1.0.2` — программная генерация и модификация структуры `.pptx`.
- `matplotlib>=3.9.0`, `numpy>=2.0.0`, `scipy>=1.14.0` — расчет и рендер научных графиков и схем (`300 DPI`).
- `Pillow>=10.4.0` — обработка растровых изображений, иконок и проверка размеров.
- `pywin32>=306` — COM-интерфейс `win32com.client` для пакетного экспорта слайдов в PNG Full HD.

## 2. Режимы работы: MCP `powerpoint` vs `python-pptx`

| Задача | Рекомендуемый режим | Как выполнять |
| :--- | :--- | :--- |
| **Интерактивная работа с пользователем на экране**, точечная правка слайдов, показ презентации вживую | **Живой режим через MCP `powerpoint`** | `manage_presentation(action="open" \| "create")`, затем `add_slide_with_layout`, `populate_placeholder`, `switch_slide`, `add_speaker_notes`, `slide_snapshot`. |
| **Генерация полной лекции (15–18 слайдов) с нуля**, вариативное прототипирование макетов | **Гибридный конвейер (`python-pptx` + MCP `powerpoint`)** | 1) Расчет графиков (`matplotlib`).<br>2) Сборка `.pptx` скриптом `template_deck_builder.py` / `build_lecture_XX.py`.<br>3) Просмотр в живом окне через MCP `manage_presentation` или COM-экспорт превью. |
| **Пакетный рендер превью и автоматическая проверка (QA)** | **Пакетный режим (`python-pptx` + `export_slide_previews.py`)** | Запуск скрипта сборки + экспорт слайдов в Full HD PNG в папку превью для анализа. |

> **Правило блокировки файлов:** Перед запуском сборки `python-pptx` закрывайте презентацию в живом PowerPoint (`manage_presentation(action="close")`), чтобы исключить ошибку разделяемого доступа Windows `PermissionError`.

## 3. Фирменный стиль и дизайн-код ГУАП (SUAI Design Code)

Все презентационные материалы курса создаются в строгом соответствии с корпоративным стилем ГУАП (`docs/design_guide_presentation.md` и шаблон `course_materials/templates/guap_16-9_2023.pptx`).

### 3.1. Геометрия холста и поля безопасности (16:9 Widescreen)
- **Ширина слайда:** `13.333"` (`960.0 pt` / `12 192 000` EMU).
- **Высота слайда:** `7.500"` (`540.0 pt` / `6 858 000` EMU).
- **Поля безопасности:** левое и правое поля — строго `0.60"` (`43.2 pt`), верхнее поле — `0.45"` (`32.4 pt`).
- **Полезная ширина контента:** `12.133"` (`13.333" - 2 × 0.60"`).

### 3.2. Мастер-шапка слайда (Master Header)
Каждый контентный слайд (Slides 2+) обязан содержать стандартизированную шапку:
1. **Заголовок слайда:** `left = 0.60"`, `top = 0.45"`, `width = 10.51"`, `height = 0.45"`, `Arial Bold 20–24 pt`, цвет `SUAI Deep Navy` (`#002C5F`).

3. **Фирменная 3-точечная градиентная линия (Signature Line):**
   - Положение: `left = 0.60"`, `top = 1.06"`, `width = 12.133"`, `height = 0.0"`, толщина `1.25 pt`.
   - Градиентная заливка: трехточечный линейный переход слева направо:
     - **0% (Старт):** `#005AAA` (SUAI Primary Blue)

## 4. Когнитивная эргономика: Бритва Оккама и Принцип Парето

Университетская лекция предназначена для быстрой когнитивной синхронизации лектора и студентов. Перегрузка слайдов текстом разрушает восприятие.

### 4.1. Закон плотности контента (1 слайд = 2–3 емкие фразы)
- **Принцип Парето (80/20):** 80% понимания физики явления обеспечивается 20% ключевых визуально-смысловых акцентов.
- **Лимит объема текста:** не более **35–45 слов** на всем слайде (не считая формульных обозначений и подписей к рисункам).
- Каждая карточка содержит максимум **1–2 лаконичных тезиса**, сформулированных строго в категоричной утвердительной форме.

### 4.2. Категорический запрет риторических вопросов и формата «вопрос-ответ»
Риторические вопросы на слайдах («Что такое дзета-потенциал?», «Почему золь Фарадея устойчив?», «Как остановить коагуляцию?») **строго запрещены**. Слайд обязан формулировать строгое физико-инженерное утверждение.

- ❌ *«Почему нанозоль золота не слипается 170 лет?»*  
  ✔️ **«Электростатический барьер ДЭС ($\zeta > 30\text{ мВ}$) блокирует ван-дер-ваальсову агрегацию золя Фарадея с 1857 г.»**
- ❌ *«В чем заключается термодинамический парадокс?»*  
  ✔️ **«Избыток свободной поверхностной энергии $\Delta G_s = \sigma \cdot S > 0$ делает любую нанодисперсию термодинамически метастабильной.»**
- ❌ *«Как предотвратить седиментацию наночастиц?»*  
  ✔️ **«Броуновская диффузия преодолевает гравитационное оседание Стокса при радиусе наночастиц $r < 10\text{ нм}$.»**

### 4.3. Механизм разгрузки слайда: Заметки докладчика (`Speaker Notes`)
Все развернутые пояснения, исторический контекст, методические подсказки и расширенные формульные выкладки переносятся в `notes_slide` каждого слайда и живой конспект речи `lecture_XX_speech.md`.

## 6. Регламент ввода терминов и аббревиатур (Правило R3)

Запрещено использовать специализированные термины и аббревиатуры без предварительного пояснения:
1. **Первое появление термина на слайдах:**
   - Обязательно указывается **полное развернутое академическое наименование** на русском языке.
   - Сразу после него в круглых скобках приводится **общепринятая аббревиатура**.
   - Термин визуально выделяется **полужирным шрифтом** или фирменным цветом `#005AAA`.
   - *Эталон:* «...стабильность дисперсии обеспечивает **двойной электрический слой (ДЭС)**...»
2. **Последующее использование:**
   - Допускается использовать краткую аббревиатуру без расшифровки («...в плотной части ДЭС...»).
3. **Обязательный глоссарий курса:**
   - **двойной электрический слой (ДЭС)**
   - **теория Дерягина–Ландау–Фервея–Овербека (ДЛФО)**
   - **потенциалопределяющие ионы (ПОИ)**
   - **противоионы (ПИ)**
   - **электрокинетический дзета-потенциал ($\zeta$)**
   - **поверхностно-активные вещества (ПАВ)**
   - **критическая концентрация мицеллообразования (ККМ)**
   - **динамическое рассеяние света (ДРС)**
   - **сканирующая электронная микроскопия (СЭМ)**
   - **просвечивающая электронная микроскопия (ПЭМ)**
   - **атомно-силовая микроскопия (АСМ)**
   - **рентгенодифракционный анализ (РДА)**

## 7. Стандарт научной достоверности визуальных данных (Правило R4)

1. **Категорический запрет ИИ-псевдоиллюстраций:**
   - Полностью запрещено применение картинок, сгенерированных диффузионными сетями (Midjourney, DALL-E, Stable Diffusion и др.). Они содержат антинаучные артефакты: искаженные кристаллические решетки, выдуманные атомные связи и ложные масштабы.
2. **Санкционированные категории графики:**
   - **Подлинные исторические музейные артефакты:** реальное фото колбы золя золота Майкла Фарадея 1857 г. из The Royal Institution (Лондон).
   - **Аутентичные микрофотографии СЭМ/ПЭМ:** реальные микрофотографии агрегатов наночастиц магнетита ($Fe_3O_4$), золота ($Au$) или диоксида титана ($TiO_2$) из рецензируемых научных статей с указанием масштабной линейки (scale bar) и источника (CC BY).
   - **Математически точные аналитические графики `matplotlib`:** построение кривых строго по физическим уравнениям (ДЛФО, Юнг, Кельвин, Пуазейль) с экспортом при `dpi=300`. Ручная подгонка графиков «на глаз» запрещена.

## 9. Каталог типовых макетов слайдов (Slide Layout Catalog)

Подробные спецификации координат и сеток см. в [references/slide-layout-patterns.md](./references/slide-layout-patterns.md) и [references/suai-design-standards.md](./references/suai-design-standards.md).

- **Layout T (Title Slide — Титульный лист университета):**
  - Официальный логотип ГУАП (`guap_logo_extracted.png` или белый `guap_logo_white.png`), название лекции 28–32 pt Bold, преподаватель (доцент Попов Д.А.), Кафедра №3, привязка к курсу («ФОН», 3 курс, Лекция №3).
  - *Правило однократного указания (Single-Point Occurrence):* данные преподавателя и кафедры указываются строго на титуле и не повторяются на последующих слайдах лекции.
- **Layout P (Problem Intro — Вводный проблемный слайд):**
  - Шапка с градиентной линией и логотипом ГУАП.
  - Левая половина: сетка 2×3 карточек 6 технологических проблем с иконками-маркерами.
  - Правая половина: доминирующая подлинная научная иллюстрация (колба Фарадея / СЭМ агрегации).
  - Нижний баннер ключевого вывода (Takeaway).
- **Layout S (Section Divider — Слайд-разделитель / Открытие проблемы):**
  - Центрированная композиция, крупная иконка-маркер проблемы (`1.4" × 1.4"`).
  - Заголовок раздела / проблемы 24–28 pt Bold.
  - Физический тезис строго в 1–2 предложения, задающий противоречие.
  - Нижняя дорожная карта решения (Roadmap Pills).
- **Layout C (Comparative Variation Matrix — Сравнительная матрица вариаций):**
  - 3 миниатюры слайдов (ширина `3.85"` каждая) для экспертного ревью дизайн-вариаций.
  - Аналитические карточки сравнения с оценкой критериев брендинга, лаконичности и читаемости.
- **Layout A (Two-Column Analytical — Двухколоночный аналитический):**
  - Левая колонка (42%): карточки теории, выделенные законы и формулы.
  - Правая колонка (58%): график `matplotlib` 300 DPI или схема.
  - Нижний баннер вывода Takeaway.
- **Layout B (Wide Sequence — Полноширинный 3-стадийный):**
  - Верхний ряд: 2–3 карточки стадий процесса.
  - Нижняя панель: полноширинная аналитическая диаграмма механизма.

## 10. Пошаговый рабочий процесс создания лекции (5 этапов)

1. **Этап 1. Проектирование и план лекции (`lecture_XX_plan.md`):**
   - Выделение 3–4 главных практических навыков («Уметь») и теоретических законов («Знать») по РПД.
   - Послайдовый план на 15–18 слайдов с жестким соблюдением лимита 2–3 фразы на слайд.
2. **Этап 2. Сборка заготовок (`template_deck_builder.py`):**
   - Создание каркаса презентации с Layout T, Layout P, Layout S и рабочими слайдами.
3. **Этап 3. Генерация научной графики (`matplotlib`, 300 DPI):**
   - Построение строгих аналитических графиков без ручной подгонки, подбор реальных СЭМ/ПЭМ фото.
4. **Этап 4. Сборка презентации и написание речи лектора (`lecture_XX_speech.md`):**
   - Вставка иллюстраций, запись тезисов в `notes_slide`, составление полного живого конспекта речи.
5. **Этап 5. Верификация и рендер превью (`export_slide_previews.py`):**
   - Пакетный экспорт в Full HD PNG, проверка чек-листа дизайн-кода (поля, градиентная линия, лаконичность, отсутствие риторических вопросов, отсутствие упоминаний ЛР).
