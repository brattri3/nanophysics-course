# Scientific Presentation Creator

Этот навык определяет стандарт разработки академических и научно-технических презентаций (`.pptx`) двумя взаимодополняющими способами:
1. **Интерактивное управление живым окном Microsoft PowerPoint через MCP-сервер `powerpoint`** (пошаговое создание/редактирование на экране пользователя, переключение слайдов, снимки `slide_snapshot`, шаблоны и заметки).
2. **Пакетная кодогенерация на Python (`python-pptx` + `matplotlib`/`numpy` + `pywin32`)** (быстрая сборка презентации целиком, высокоточные расчетные графики `300 DPI` и массовый рендер превью).

---

## 1. Архитектура инструментов и зависимости (Dependencies & Requirements)

Для полноценной работы навыка в проекте должны быть доступны следующие программы, MCP-серверы и Python-пакеты (прописанные в корневых `pyproject.toml`, `requirements.txt` и `README.md`):

### 1.1. Внешние приложения (OS & Desktop Applications)
- **ОС:** Windows (требуется для COM-автоматизации `PowerPoint.Application` и MCP-сервера `powerpoint`).
- **Microsoft PowerPoint (Desktop / Office 365 / 2019+):** обязателен как для живого управления через MCP-сервер `powerpoint`, так и для точного рендера PNG-превью слайдов через `pywin32` (`Slide.Export`).
- **Менеджер окружения `uv`:** для запуска генераторов (`uv run python ...`).

### 1.2. Подключенные MCP-серверы (MCP Servers)
- **MCP-сервер `powerpoint`** (схемы инструментов расположены в `<appDataDir>/mcp/powerpoint/*.json`, вызов через `call_mcp_tool(ServerName="powerpoint", ToolName=..., Arguments=...)`):
  - `manage_presentation` — открытие (`open`), создание (`create`), сохранение (`save`, `save_as`) и закрытие (`close`) презентации в живом окне PowerPoint (пути передаются в формате Windows с двойным обратным слэшем `\\`).
  - `list_templates` / `analyze_template` — просмотр доступных шаблонов `.potx`/`.pptx` и анализ макетов/плейсхолдеров.
  - `add_slide_with_layout` / `populate_placeholder` — добавление слайда с выбранным макетом и заполнение его текстовых/графических плейсхолдеров.
  - `manage_slide` — дублирование (`duplicate`), перемещение (`move`) и удаление (`delete`) слайдов.
  - `switch_slide` — переключение активного слайда на экране пользователя (1-based индекс).
  - `slide_snapshot` — мгновенный снимок текущего слайда из открытого окна PowerPoint для визуальной проверки.
  - `add_speaker_notes` — запись текста речи лектора в заметки докладчика активного или указанного слайда.
  - `add_animation` — добавление точечной анимации в открытой презентации (при явном запросе пользователя).
  - `evaluate` — прямое выполнение произвольного COM/VBA-выражения над объектной моделью активной презентации PowerPoint для тонкой настройки фигур, таблиц и шрифтов.
- *(Опционально для 3D-структур кристаллов, цеолитов и биомолекул)* **MCP-сервер `science_biomolecular_structure_viewer_mcp`** — интерактивная 3D-визуализация структур `.cif`/`.pdb` в боковой панели.

### 1.3. Python-библиотеки (прописаны в `pyproject.toml` и `requirements.txt`)
- `python-pptx>=1.0.2` — программная генерация и модификация структуры `.pptx`.
- `matplotlib>=3.9.0`, `numpy>=2.0.0`, `scipy>=1.14.0` — аналитический расчет и рендер научных графиков и физических схем (`300 DPI`).
- `Pillow>=10.4.0` — обработка растровых изображений и проверка размеров.
- `pywin32>=306` — COM-интерфейс `win32com.client` для пакетного экспорта слайдов в PNG через движок PowerPoint.

## 2. Режимы работы: когда использовать MCP `powerpoint`, а когда `python-pptx`

| Задача | Рекомендуемый режим | Как выполнять |
| :--- | :--- | :--- |
| **Интерактивная работа с пользователем на экране**, правка отдельных слайдов, показ слайдов вживую, работа по корпоративному шаблону `.potx` | **Живой режим через MCP `powerpoint`** | Вызвать `manage_presentation(action="open" \| "create")`, затем управлять слайдами через `add_slide_with_layout`, `populate_placeholder`, `switch_slide`, `add_speaker_notes`, `evaluate` и проверять через `slide_snapshot`. |
| **Генерация полной лекции (15–18 слайдов) с нуля** или глобальный редизайн шрифтов/карточек на всех слайдах сразу | **Гибридный конвейер (`python-pptx` + MCP `powerpoint`)** | 1) Построить графики (`matplotlib`).<br>2) Собрать базовый `.pptx` скриптом `python-pptx` за 1 секунду.<br>3) Открыть результат в живом окне через `manage_presentation(action="open")` или выгрузить превью через [export_slide_previews.py](./scripts/export_slide_previews.py). |
| **Быстрая фоновая ревизия субагентами** (без перехвата фокуса окна на экране пользователя) | **Пакетный режим (`python-pptx` + `export_slide_previews.py`)** | Скрипт сборки `.pptx` + фоновый COM-экспорт всех слайдов в папку `previews_lXX/` для чтения через `read_file`. |

> **Важное правило блокировки файлов:** Нельзя одновременно перезаписывать файл `.pptx` скриптом `python-pptx`, пока этот же файл открыт в живом окне Microsoft PowerPoint (Windows заблокирует запись). Перед запуском `python-pptx` закройте презентацию через `manage_presentation(action="close")`, а после пересборки снова откройте через `manage_presentation(action="open", file_path=...)`.

## 3. Пошаговый рабочий процесс (5 этапов)

### Этап 1. Проектирование, план лекции и матрица навыков (Curriculum & Skills Matrix)
1. **Сверка с РПД и календарным планом:**
   - Изучите `course_materials/rpd.md` и `course_materials/semester_4/calendar_thematic_plan.md`.
   - Выделите ключевые дидактические единицы, физические законы и связь с лабораторным практикумом (ЛР).
2. **Формирование Матрицы навыков и знаний студента:**
   - Сформулируйте **3–4 главных практических навыка («Уметь»)** и соответствующих теоретических знаний («Знать»), которые студент унесет с лекции для защиты лабораторных работ и сдачи зачета/экзамена.
3. **Составление послайдового плана (`lecture_XX_plan.md`):**
   - Оптимальный объем 90-минутной лекции (1 пара): **15–18 слайдов** (~5 минут на слайд).
   - Для каждого слайда зафиксируйте заголовок, тезисы левой колонки, ТЗ на график правой колонки и проверяемый навык.

### Этап 2. Создание каркаса заготовок (Placeholder Deck)
- **Правило заготовок:** Не рисуйте сложную графику до создания полной структуры документа.
- Создайте `lecture_XX_<topic>.pptx` со **всеми слайдами лекции** (через скрипт на базе [template_deck_builder.py](./scripts/template_deck_builder.py) или через MCP `manage_presentation` + `add_slide_with_layout`).

### Этап 3. Генерация математически точных иллюстраций
- Все графики и физические схемы создаются программно через `matplotlib` + `numpy` в высоком разрешении (`dpi=300`) и сохраняются в каталог `figures/` или `scripts/presentation_generator/`.
- **Запрет на ручное смещение («на глаз»):** Все характерные точки (пересечения, экстремумы, линии ликвидуса/солидуса, коноды, потенциалы ДЭС, кривые ДЛФО и т.д.) вычисляются строго по аналитическим уравнениям модели. Точка на графике обязана иметь координаты `(x, f(x))`, вычисленные той же функцией, что строит кривую.
- Подробные правила точности см. в [diagram-precision-guide.md](./references/diagram-precision-guide.md).

### Этап 4. Сборка, речь лектора (`lecture_XX_speech.md`) и заметки докладчика
- Вставьте сгенерированные иллюстрации в соответствующие слайды.
- Запишите краткие тезисы и яркие физические аналогии в `notes_slide` каждого слайда (или через MCP `add_speaker_notes`).
- Напишите полный живой конспект речи лектора `lecture_XX_speech.md` с бытовыми аналогиями и ответами на типичные вопросы студентов, строго синхронизировав все числа в речи с подписями на графиках.

### Этап 5. Визуальная и педагогическая верификация (Ревью глазами студента)
- Экспортируйте превью слайдов (через [export_slide_previews.py](./scripts/export_slide_previews.py) или MCP `slide_snapshot`) и проверьте отсутствие наложений текста, выходов за поля и переносов коротких формул.
- При необходимости подключите субагента-ревьюера в роли **среднего студента 3 курса**, чтобы отсеять перегруженные пятиэтажные формулы (оставив на слайдах физические зависимости и пошаговые рецепты решения задач) и проверить крупность шрифта.
- Если пользователь хочет посмотреть или доработать презентацию интерактивно — откройте ее на экране через MCP `manage_presentation(action="open", file_path=...)`.

## 4. Ключевые правила оформления и педагогического дизайна

1. **Отказ от хрупких многослойных анимаций в пользу наглядных прогрессий:**
   - По умолчанию вместо сложных путей перемещения внутри одного слайда используйте **многопанельные последовательности (`А → Б → В`)** на единой сетке или серию последовательных слайдов. Если пользователь явно просит добавить анимацию появления в живом PowerPoint — используйте MCP-инструмент `add_animation`.
2. **Геометрия и модульная сетка (16:9 Widescreen):**
   - Размер слайда: `13.333 x 7.5` дюймов.
   - Шапка слайда: `top = 0.25"–0.4"`, `height = 0.8"`.
   - Рабочая область: `top = 1.25"–1.35"`, `bottom = 6.75"–7.0"`.
   - Типовые макеты и координаты приведены в [slide-layout-patterns.md](./references/slide-layout-patterns.md).
3. **Типографика и читаемость с задней парты:**
   - Шрифт: `Arial` / `Calibri` для текста, `Consolas` для выделенных строк формул `[Ф]`.
   - Заголовки слайдов: `20–24 pt Bold`; заголовки карточек: `13–14 pt Bold`; основной текст карточек: **не менее `11.4–14 pt`** (не мельчите до `9–10 pt` — лучше сократить воду и оставить 2–3 емких буллита на карточку!).
   - Академическая цветовая палитра:
     - Темно-синий (Основной): `#003366` / `RGB(0, 51, 102)`
     - Грифельно-серый (Текст): `#222222` / `RGB(34, 34, 34)`
     - Акцентный синий (Формулы и рамки): `#0050B3` / `RGB(0, 80, 179)`
     - Акцентный красный/коралловый (Важное/Барьер): `#CC3333` / `RGB(204, 51, 51)`
     - Изумрудный (Устойчивость/Выигрыш): `#1B7837` / `RGB(27, 120, 55)`
     - Светлый фон карточек: `#F5F8FC` / `RGB(245, 248, 252)`
