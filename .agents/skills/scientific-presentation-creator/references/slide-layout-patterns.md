# Шаблоны компоновки слайдов (Slide Layout Patterns)

Все презентации создаются в широкоэкранном стандарте **16:9** (`13.333 × 7.5` дюймов). Ниже приведены проверенные модульные сетки для `python-pptx`.

---

## 1. Глобальная координатная сетка слайда

- **Ширина слайда:** `13.333"`
- **Высота слайда:** `7.500"`
- **Поля безопасности:** левое/правое `0.5"`, верхнее `0.35"`, нижнее `0.4"`.
- **Зона заголовка:**
  - `left = 0.5"`, `top = 0.35"`, `width = 12.333"`, `height = 0.85"`
  - Текст заголовка: `24–26 pt Bold`, цвет `#003366`.
  - Подзаголовок / навигационная строка (опционально): `13 pt Italic`, цвет `#556677`.
- **Нижний колонтитул / ключевой вывод (Takeaway Banner):**
  - `left = 0.5"`, `top = 6.65"`, `width = 12.333"`, `height = 0.55"`
  - Плашка со скругленными углами, фон `#EEF4FA`, рамка `#0055AA`, текст `13–14 pt Bold`.

---

## 2. Типовые макеты (Layouts)

### Макет А: Двухколоночный «Теория + Диаграмма» (Основной рабочий макет)
Используется для большинства слайдов с выводом формул и графическим анализом.
- **Левая колонка (Тезисы и формулы, 42% ширины):**
  - `left = 0.5"`, `top = 1.35"`, `width = 5.3"`, `height = 5.1"`
  - Внутри: 1–2 структурированных карточки (Определение, Закон/Формула, Физический смысл).
- **Правая колонка (Иллюстрация / График, 58% ширины):**
  - `left = 6.0"`, `top = 1.35"`, `width = 6.8"`, `height = 5.1"`
  - Изображение масштабируется с сохранением пропорций (`width` или `height` по ограничивающей рамке с центрированием).

### Макет Б: Полноширинная последовательность (3 стадии процесса)
Используется вместо анимаций для демонстрации стадий механизма (например, коагуляция, мицеллообразование, VLS-рост).
- **Верхний вводный блок:**
  - `left = 0.5"`, `top = 1.30"`, `width = 12.333"`, `height = 0.9"`
- **Многопанельная схема (на всю ширину):**
  - `left = 0.6"`, `top = 2.30"`, `width = 12.1"`, `height = 4.1"`
- **Нижний вывод (Takeaway):**
  - `left = 0.5"`, `top = 6.60"`, `width = 12.333"`, `height = 0.55"`

### Макет В: Сравнительная матрица (3 колонки / Таблица)
Используется для сопоставления классов систем (например: Золи vs Гели vs Ксерогели, или Доэвтектика vs Эвтектика vs Заэвтектика).
- **3 колонки равной ширины:**
  - Колонка 1: `left = 0.5"`, `top = 1.35"`, `width = 3.9"`, `height = 5.1"`
  - Колонка 2: `left = 4.7"`, `top = 1.35"`, `width = 3.9"`, `height = 5.1"`
  - Колонка 3: `left = 8.9"`, `top = 1.35"`, `width = 3.9"`, `height = 5.1"`

---

## 3. Обязательные требования к заметкам докладчика (`notes_slide`)

Каждый слайд должен содержать заполненные заметки докладчика по следующей структуре:
1. **Ключевой тезис слайда** (1–2 предложения).
2. **Пояснение к формулам и обозначениям** (расшифровка всех переменных).
3. **Комментарий к графику/схеме** (куда обратить взгляд аудитории: «Обратите внимание на кривую 2...»).
4. **Мостик к следующему слайду** (логический переход).
