# Шаблоны компоновки слайдов (Slide Layout Patterns)

Все академические и научно-технические презентации курса создаются в широкоэкранном стандарте **16:9** (`13.333 × 7.500` дюймов) с соблюдением корпоративного брендбука ГУАП и дизайн-кода курса (см. [suai-design-standards.md](./suai-design-standards.md)).

---

## 1. Базовая координатная сетка холста (16:9 Grid)

- **Размер холста:** `13.333" × 7.500"` (`960 × 540 pt` / `12 192 000 × 6 858 000` EMU).
- **Поля безопасности:**
  - Левое и правое поля: строго `0.600"` (`43.2 pt`).
  - Верхнее поле: `0.450"` (`32.4 pt`).
  - Нижнее поле: `0.300"` (`21.6 pt`).
- **Полезная ширина холста:** `12.133"` (`873.6 pt`).
- **Мастер-шапка слайда (Master Header, слайды 2+):**
  - Заголовок: `left = 0.60"`, `top = 0.45"`, `width = 10.51"`, `height = 0.45"`, `Arial Bold 20–24 pt`, `#002C5F`.
  - Компактный логотип ГУАП: `left = 11.62"`, `top = 0.45"`, `width = 1.11"`, `height = 0.34"`.
  - Градиентная разделительная линия (Signature Line):
    - `left = 0.60"`, `top = 1.06"`, `width = 12.133"`, `height = 0.0"`, толщина `1.25 pt`.
    - Линейный градиент $0^\circ$: `#005AAA` (0%) $\to$ `#00BEF3` (54%) $\to$ `#E70F47` (100%).
- **Нижний баннер ключевого вывода (Takeaway Banner):**
  - `left = 0.60"`, `top = 6.65"`, `width = 12.133"`, `height = 0.55"`.
  - Скругленный прямоугольник, фон пастельный серо-голубой `#EEF4FA`, рамка `1.2 pt` цвета `#005AAA`, текст `Arial Bold 12.5–13.0 pt`, цвет `#002C5F`.

### 2.1. Layout T: Титульный лист университета (Title Slide)
Используется для открытия лекции и фиксации академического статуса.
- **Правило однократного указания (Single-Point Occurrence):** реквизиты преподавателя (доцент Попов Д.А.), кафедры (Кафедра №3 «Физики и нанотехнологий»), номер курса (3 курс) и название дисциплины («Физические основы нанотехнологий») указываются **ТОЛЬКО** на титульном слайде. На последующих слайдах они не дублируются.
- **Геометрия элементов:**
  - Логотип ГУАП: `left = 0.80"`, `top = 0.80"`, `width = 3.20"`, `height = 0.65"` (файл `guap_logo_extracted.png` на светлом фоне или `guap_logo_white.png` на темном фоне).
  - Строка курса: `left = 0.80"`, `top = 2.10"`, `width = 11.50"`, `height = 0.40"`, `Arial Bold 13 pt`, `#5A6978`.
  - Заголовок темы: `left = 0.80"`, `top = 2.60"`, `width = 11.50"`, `height = 1.30"`, `Arial Bold 28–32 pt`, `#002C5F` (или `#FFFFFF`).
  - Подзаголовок темы: `left = 0.80"`, `top = 4.00"`, `width = 11.50"`, `height = 0.70"`, `Arial Bold 15–16 pt`, `#005AAA` (или `#00BEF3`).
  - Плашка преподавателя: `left = 0.80"`, `top = 5.50"`, `width = 11.50"`, `height = 0.80"`, `Arial Regular 13 pt`, текст: *«Преподаватель: доцент Попов Д.А. | Кафедра №3 «Физики и нанотехнологий» ГУАП | Санкт-Петербург, 2026»*.
- **Вариации исполнения:**
  - *T1 (Corporate Classic):* белый фон, полноцветный логотип ГУАП, акцентная линия `#005AAA`.
  - *T2 (Tech Split):* левая информационная плашка `#F4F7FA`, правая фотопанель кафедры.
  - *T3 (Deep Navy Prestige):* глубокий темно-синий фон `#002C5F`, инвертированный белый логотип `guap_logo_white.png`, белая и циановая (`#00BEF3`) типографика.

### 2.2. Layout P: Вводный проблемный слайд (Problem Intro)
Используется для фронтальной постановки 6 технологических вызовов перед переходом к теории.
- **Шапка:** стандартная мастер-шапка с градиентной линией и компактным логотипом ГУАП.
- **Левая колонка — Сетка проблем 2×3 (`left = 0.60"`, `top = 1.35"`, `width = 5.75"`, `height = 5.05"`):**
  - Содержит 6 карточек (`#F4F7FA`, рамка `#C8D7E6`), сгруппированных по 2 в ряд (строки с интервалом `1.65"`):
    - Ряд 1: Проблема 1 (Агрегация / Слипание, `#E70F47`) и Проблема 2 (Седиментация / Осадок, `#002C5F`).
    - Ряд 2: Проблема 3 (Хранение / Старение, `#FF6418`) и Проблема 4 (Транспорт / Доставка, `#9269C9`).
    - Ряд 3: Проблема 5 (Сепарация / Калибровка, `#00BEF3`) и Проблема 6 (Технологичность / Формуляция, `#009A49`).
  - Каждая карточка: `width = 2.75"`, `height = 1.50"`, круглая иконка-маркер (`0.48" × 0.48"`), название `Arial Bold 11.5 pt`, управляющая формула `Arial Regular 10 pt`.
- **Правая колонка — Подлинная научная иллюстрация (`left = 6.65"`, `top = 1.35"`, `width = 6.08"`, `height = 5.05"`):**
  - Подлинная фотография колбы золя золота Майкла Фарадея 1857 г. или микрофотография СЭМ агрегации наночастиц с масштабной линейкой и точной атрибуцией (The Royal Institution / MDPI).
- **Нижний баннер Takeaway:** `top = 6.65"`, ключевой физический вывод о необходимости стабилизации наносистем.

### 2.3. Layout S: Слайд-разделитель / Открытие проблемы (Section Divider)
Используется как мощный когнитивный якорь при открытии нового раздела или конкретной проблемы наноматериалов.
- **Фон:** чистый белый (`#FFFFFF`) или фирменный темно-синий (`#002C5F`).
- **Центрированная композиция:**
  - Крупная круглая иконка-маркер проблемы: `left = 5.96"`, `top = 1.60"`, `width = 1.40"`, `height = 1.40"`.
  - Надзаголовок проблемы: `left = 1.50"`, `top = 3.20"`, `width = 10.33"`, `height = 0.35"`, `Arial Bold 13 pt`, цвет темы соответствующей проблемы (например, `#E70F47` для Агрегации).
  - Заголовок проблемы / раздела: `left = 1.00"`, `top = 3.55"`, `width = 11.33"`, `height = 0.70"`, `Arial Bold 26–28 pt`, цвет `#002C5F` (или `#FFFFFF`).
  - Поясняющий физический тезис: `left = 1.40"`, `top = 4.35"`, `width = 10.53"`, `height = 0.85"`, строго **1–2 емких предложения** (`15–17 pt`), формулирующих противоречие/парадокс.
  - Навигационная цепочка решения (Roadmap Pills): `left = 2.00"`, `top = 5.45"`, `width = 9.33"`, `height = 0.45"`, 3–4 плашки последовательных шагов лекции.

### 2.4. Layout C: Сравнительная матрица вариаций (Comparative Matrix)
Используется для экспертного ревью и сопоставления нескольких вариантов оформления слайда.
- **Шапка:** заголовок слайда + подзаголовок сравнения + градиентная линия.
- **3 колонки превью (`top = 1.35"`):**
  - Колонка 1 (Вариация 1): `left = 0.60"`, `width = 3.85"`, превью слайда (`height = 2.16"`), ниже карточка критериев (`top = 3.65"`, `height = 2.80"`).
  - Колонка 2 (Вариация 2): `left = 4.74"`, `width = 3.85"`, превью слайда (`height = 2.16"`), ниже карточка критериев (`top = 3.65"`, `height = 2.80"`).
  - Колонка 3 (Вариация 3): `left = 8.88"`, `width = 3.85"`, превью слайда (`height = 2.16"`), ниже карточка критериев (`top = 3.65"`, `height = 2.80"`).
- **Карточка критериев:**
  - Бренд-код ГУАП (логотип, палитра, гарнитура Arial).
  - Плотность текста и Бритва Оккама (до 35–45 слов, отсутствие риторических вопросов).
  - Фокус внимания аудитории и наглядность.
- **Нижний баннер вывода:** `top = 6.65"`, итоговое экспертное резюме.

---

### 2.5. Layout A: Двухколоночный аналитический макет (Two-Column Analytical)
Основной рабочий макет лекции для разбора теорий, формул и расчетных зависимостей.
- **Левая колонка — Теоретический блок (`left = 0.60"`, `top = 1.35"`, `width = 5.35"`, `height = 5.05"`):**
  - 1–2 информационные карточки (`#F4F7FA`, контур `#C8D7E6`, `1.0 pt`).
  - Внутри: заголовок карточки `13.5 pt Bold Navy`, текст `11.5–12.5 pt Regular Charcoal` (не более 2 тезисов на карточку!), математический закон `13 pt Bold Blue`.
  - При первом вводе терминов применяется правило R3: **полное наименование (АББРЕВИАТУРА)**.
- **Правая колонка — Расчетный график или микрофото (`left = 6.20"`, `top = 1.35"`, `width = 6.53"`, `height = 5.05"`):**
  - Высокоточный график `matplotlib` (`dpi=300`), построенный по аналитическому уравнению модели, либо подлинная микрофотография СЭМ/ПЭМ с масштабной линейкой.
- **Нижний баннер Takeaway:** `top = 6.65"`, `width = 12.133"`, `height = 0.55"`.

### 2.6. Layout B: Полноширинный диаграммный макет (Wide Diagram)
Используется для иллюстрации многостадийных процессов (золь-гель переход, стадии кристаллизации, строение ДЭС по Штерну).
- **Верхний вводный ряд (`left = 0.60"`, `top = 1.35"`, `width = 12.133"`, `height = 1.15"`):**
  - 3 горизонтальные карточки стадий (`width = 3.85"` каждая с отступом `0.29"`).
- **Нижняя полноширинная панель (`left = 0.60"`, `top = 2.65"`, `width = 12.133"`, `height = 3.80"`):**
  - Полноширинный график `matplotlib` 300 DPI или схема взаимодействия.
- **Нижний баннер Takeaway:** `top = 6.65"`, `width = 12.133"`.

## 3. Требования к заметкам докладчика (`notes_slide`)

Каждый слайд в обязательном порядке снабжается текстом заметок для лектора:
1. **Ключевой физический тезис** (1–2 предложения, которые лектор проговаривает в первые 10 секунд).
2. **Семантика формул и физических величин** (строгая расшифровка обозначений).
3. **Комментарий к иллюстрации** («Обратите внимание на точку перегиба потенциала на границе слоя Штерна...»).
4. **Методический мостик** (логический переход к следующему слайду лекции).
