# Дизайн-Манифест и Архитектура Представления Материалов
*(Anti-Slop Design Guidelines)*

## 1. Концепция «Scientific Slate»
Для академических презентаций по курсу «Физические основы нанотехнологий» выбран строгий, высококонтрастный и минималистичный стиль, исключающий "AI Slop" (дешевые градиенты, бессмысленное свечение, перегруженные карточки карточек).

### 1.1. Типографика (Шрифтовая пара)
*   **Заголовки (Headings):** `Newsreader` (Serif). Выбран для передачи классического академического веса. Ассоциируется с научными статьями, учебниками и серьезной периодикой.
*   **Основной текст (Body) и данные:** `Manrope` (Sans-serif). Технический, читаемый, без лишних засечек, идеально подходит для графиков, формул и интерфейсов.

### 1.2. Цветовая палитра
*   **Фон (Canvas):** Строгий `neutral-950` (почти черный) и `neutral-900` для карточек.
*   **Текст:** `white` для заголовков, `neutral-300` для основного текста.
*   **Акцент (Functional Accent):** `emerald-400` / `emerald-500`. Используется исключительно для смыслового выделения (например, текущей точки на графике, ключевого термина или кнопки действия).
*   **Правило контраста:** Никакого серого текста на цветном фоне. Никаких пурпурно-синих хакерских градиентов.

### 1.3. Сетка и математика отступов
*   Внутренние отступы контейнера всегда больше или равны расстоянию между дочерними элементами.
*   Закругления (Border Radius) ограничены (не более 16px для основных блоков).
*   Презентационный холст имеет соотношение сторон **16:9** (формат экрана) и центрируется с помощью Flexbox.

## 2. Архитектура Презентационного Движка
*   **Компонент `SlideViewer`**: 
    *   Полноэкранный React-компонент, работающий поверх основного интерфейса (`z-50`).
    *   Использует `framer-motion` для строгих пружинных (`spring`) анимаций перелистывания (никаких дешевых растворений, только физически-корректное движение слайдов).
    *   Поддерживает навигацию с клавиатуры (стрелки, пробел) и скрытые зоны клика по краям экрана.
*   **Интерактивные виджеты (Simulations)**:
    *   Построены на базе `recharts` (React) и стандартных HTML5 Range Inputs.
    *   Все вычисления происходят "на лету" в браузере (например, перестроение графика уравнения Гиббса-Томсона при изменении радиуса).

## 3. Правила для LLM-Генерации Слайдов
При добавлении новых слайдов и лекций строго соблюдать следующие ограничения:
1.  **Лимит контента:** Не более 3-х логических блоков на слайде. 
2.  **Схемы как Код (Code-as-Diagrams):** Не использовать генеративные растровые изображения для графиков. Строить графики строго через `Recharts` или чистый JSX/SVG для обеспечения научной точности и интерактивности.
3.  **Генеративный Арт:** Использовать Imagen (AI Image Generation) **ТОЛЬКО** для абстрактных фонов и заставочных обложек (Macro photography, cinematic lighting), без попыток заставить диффузионную модель нарисовать точный чертеж установки.
