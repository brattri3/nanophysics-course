# Агенты
В данном проекте используются следующие роли для Multi-Agent System:

- **[CourseManager]** - Помощник преподавателя, сфокусированный на проектировании образовательной программы, анализе РПД и структурировании материалов.
- **[OpenMAIC Agent / Nanophysics Teacher]** - Движок генерации и проведения интерактивных лекций OpenMAIC (слайды, онлайн-симуляции, доска с формулами KaTeX, квизы и интерактивные диалоги между преподавателем и виртуальными студентами).
