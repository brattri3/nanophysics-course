# Физические основы нанотехнологий (Nanophysics Course)

**Университетский курс дисциплины «Физические основы нанотехнологий»**  
* Санкт-Петербургский государственный университет аэрокосмического приборостроения (ГУАП)
* Институт фундаментальной подготовки и технологических инноваций (ФПТИ), Кафедра №3 (Физика)
* Направление подготовки: **03.03.01 «Прикладные математика и физика»**
* Профиль: **«Прикладная физика и информационные технологии в наноиндустрии»**
* Трудоемкость: **7 ЗЕ (252 академических часа)** • Семестры 4 и 5

## 🚀 Развертывание и запуск на домашнем ноутбуке

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/brattri3/nanophysics-course.git
cd nanophysics-course
```

### Шаг 2. Установка зависимостей и запуск портала курса
```bash
npm install
npm run dev
```
После запуска откройте в браузере: **`http://localhost:5173/`**
* На главной странице доступен интерактивный дашборд с расписанием 26 пар, темами лекций и лабораторных работ.
* Клик по **«Лекция 1»** открывает полноэкранную презентацию со слайдами, KaTeX-формулами и «живыми» симуляторами.

## 🤖 Подключение OpenMAIC (опционально)

Для проведения занятий в виртуальном мультиагентном классе:
1. Клонируйте репозиторий OpenMAIC в корень проекта:
   ```bash
   git clone https://github.com/THU-MAIC/OpenMAIC.git
   ```
2. Создайте файл `OpenMAIC/.env.local` и укажите ваш `GOOGLE_API_KEY`:
   ```env
   GOOGLE_API_KEY=AIzaSy...
   ```
3. Запустите OpenMAIC:
   ```bash
   cd OpenMAIC
   pnpm install
   pnpm dev
   ```
   Класс доступен на **`http://localhost:3000/`**.
