## Структура рабочего пространства
Файлы распределены по папкам:
- `/course_materials/rpd.md` - Полный текст Рабочей программы дисциплины в формате Markdown
- `/course_materials/RPD_summary.md` - Краткая выжимка из РПД (часы, темы, формы контроля)
- `/course_materials/semester_4/` - Материалы 4-го семестра (лекции, лабораторные)
- `/course_materials/semester_5/` - Материалы 5-го семестра (лекции, лабораторные)
- `/course_materials/independent_work/` - Задания для самостоятельной работы (вопросы к экзамену, тесты)
- `/course_materials/literature/` - Список литературы и дополнительные источники
